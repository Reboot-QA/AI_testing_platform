# docs/ —— 跨端共享文档总录

本目录存放**跨前后端**的项目文档。包内的开发者详规遵循**就近原则**,不放这里。

## 放什么

- `Spec工作流使用指南.md` —— 团队上手文档:需求怎么进、规格落哪、代码怎么出、两人怎么接力(硬约束正文在 `.claude/rules/spec-workflow.md`,本文只讲用法)。
- 架构总览 / 部署运维总览等跨端文档(按需增补)。

## 不放什么(去哪找)

| 文档 | 位置 |
| --- | --- |
| 前端开发者详规(开发规范 / UI 设计 / 选型说明) | `frontend/docs/` |
| 后端开发者详规(后端开发规范) | `backend/docs/` |
| 前端/后端/Git/Spec 硬约束「红线」正文 | `.claude/rules/*.md`(单一事实来源) |
| AI 上下文总纲(概述/命令/架构导航) | 根 `CLAUDE.md` |
| 日志监控栈部署 | `monitoring/README.md` |
| 面向用户的项目介绍 | 根 `README.md` |
| **Spec 规格正文** | **GitLab Issue**(单一事实来源,仓库内不存;原 `docs/specs/` 已废弃删除) |
